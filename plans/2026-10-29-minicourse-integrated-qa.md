## Находки до исправлений

### P2 — абсолютные рабочие пути в двух будущих публичных документах

`2026-10-29-minicourse-implementation-handoff.md:9` и
`2026-10-29-minicourse-boundary-verification-handoff.md:12` содержат абсолютный
путь рабочего каталога. Условие: включить относящиеся untracked handoff-файлы
в публичный состав. Ожидается переносимая инструкция без локального пути;
фактически раскрывается расположение рабочего каталога. Первичный скан
зафиксировал эти две строки без вывода найденных значений; итоговый повторный
скан сохранён в `.impeccable/phase10/public-audit.json`. В Git-истории таких совпадений нет.
Исправление: описать корень проекта относительно этого документа, сохранив
смысл передачи и исторические решения.

### Открытый release gate — происхождение исторических растров

Неиспользуемые `src/assets/textures/*.webp` и старый
`docs/assets/design/approved-homepage-comp.png` входят в tracked дерево и историю.
У фактур нет точной записи генерации/условий; у старого PNG есть описание промпта
и история выбора, но нет полного исходного generation record с инструментом,
датой, условиями и хешем оригинального результата. Отсутствие использования
страницей не закрывает происхождение будущего публичного репозитория.
Не удалять материалы и не дописывать неизвестные факты; решение остаётся открытым.

Ограничение инструментов не считается дефектом продукта. Первые моментальные
контрастные замеры при смене состояния проверяются на ложные срабатывания:
сохранённый рендер confirmed показывает читаемые тёмные чернила на paper.

### P2 — адрес автора/коммиттера в публичной Git-истории

Во всех шести доступных коммитах используется один email автора и коммиттера
на общедоступном почтовом сервисе. Он не является GitHub noreply или адресом
зарезервированного example-домена. Это потенциально личная контактная метаинформация,
а не секрет приложения. Сам адрес в отчёт и выводы сканера не включён.
Доказательство: локальная агрегация полей `%ae`/`%ce` всей доступной истории;
в `public-audit.json` сохранены только счётчики. Первый коммит — `ba3a370`,
текущий — `6ae5d58`.

Ожидается явно согласованный публичный контакт или обезличенная метаинформация;
в материалах этой задачи разрешение на раскрытие именно email не установлено.
Нужно решение Виктории о допустимости его сохранения. История уже находится
в origin; локальная правка исходников не уберёт адрес из существующих коммитов.
История и Git-конфигурация не менялись; отзыв доступов не выполнялся.

### P3 — неверное описание кропа Анны в производных метаданных

В `docs/assets/portraits/prompts.json` у `anna.derivative.framing` было общее
описание круглых аватарок. Фактически `teacher-photo` имеет 4:5 и
`object-position: 50% 42%`, что видно в production-рендере и CSS. Это ошибка
описания преобразования, а не изображения или исходного промпта. Исправляется
только это поле; оригинал, SHA-256, исходный prompt и остальные записи сохраняются.

не обнаружено. Страница, принятый дизайн, расчётная версия/словарь, регистрация,

к реально используемому кропу; все четыре SHA-256 оригиналов совпадают
с реестром. JSON проверен после изменения. Исторические решения не переписаны.

Добавлены только два недостающих browser tests в
[`integrated-qa.spec.ts`](../tests/e2e/integrated-qa.spec.ts): основной путь
клавиатурой от skip-link до отмены/повтора/закрытия и целостность assets,
якорей, ARIA-ссылок, ID и всех пяти CTA с возвратом фокуса. Работающие тесты

## Code review и read-only security review

Отдельные проходы выполнила основная ассистентка. Для security применены
developer_instructions локальной read-only роли; при этом файлы не менялись.
Затем два document/privacy исправления и коррекция производной метаинформации
выполнены отдельными действиями основной работы. Независимого review не было.

Прослежены следующие границы:

- `index.astro` → `MinicourseLanding` → inline demo/К2. Контент статический;
  пользовательский ввод не рендерится через innerHTML.
- Недоверенный sessionStorage → точные пять полей/версия/status → canonical ISO,
  расписание, связь ID и времени, исходный lead time и возраст → controller →
  `textContent`/нативные элементы. Невалидная запись не становится активной.
- Время контролируется в unit/browser tests. Новые слоты и существующий
  confirmed проверяются разными правилами; замена сохраняет createdAt.
- Состояния/read/write/remove/expiry/cleanup прослежены отдельно: нет ложной
  отмены или успешной замены до storage-операции; memory-only не обещает refresh.
- Дата калькулятора → валидация/чистый расчёт/DOM; не попадает в запись демо,
  URL, cookies, localStorage, сеть или наблюдаемые логи. Нет реального контакта.
- Два проектных server entry points: страница и health. Framework добавляет
  image transformation для локальных портретов; его наличие не скрыто под
  утверждением «ровно два HTTP URL». Установленный image endpoint ограничивает
  local reads client output-каталогом, remote allowlist не настроен; отрицательный
  локальный probe вернул 403. Это не полный penetration test.
- Fake provider не импортирован route/client кодом; API чата/регистрации нет.
  Env schema server-only, browser credential не обнаружен в client bundle.
  Нет приложенческого session access, БД, auth, email, queue или analytics.

В проверенных кодовых путях не выявлено actionable воспроизводимых security
дефектов. Privacy/provenance findings перечислены отдельно и не скрыты этим
выводом. Semgrep/gitleaks в среде не найдены, их запуск не заявляется.
Проверка не охватывает инфраструктуру, TLS, rate limiting будущего хостинга,
все возможные запросы к image processor или независимый аудит зависимостей.

Доступная история — достижимые refs после fetch; удалённые/unreachable objects,
